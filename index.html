  1. 10 คะแนน — วิพากษ์ Data Model ที่อ้างอิงการออกแบบ 1 ข้อ
  2. 40 คะแนน — Normalization 4 ข้อ (1–3NF, BCNF, 4NF, 5NF)
  3. 30 คะแนน — Transaction Processing 2 ข้อ (Recovery Control, Concurrency Control)
  4. 10 คะแนน — DB Concept
  5. 15 คะแนน — ความรู้เบื้องต้นด้าน Data Warehouse (ไม่ออกการออกแบบ — อ่านเน้นความหมาย/เปรียบเทียบ)

🗺️ แผนที่เนื้อหา — เลือกหัวข้อที่จะอ่าน

10 คะแนน • พื้นฐาน

📘 DB Concept

ฐานข้อมูลคืออะไร, DBMS, Key ทุกชนิด, Anomalies, 3-Tier, Schema vs Instance, DDL/DML/DCL/TCL — เป็นฐานให้ทุกบท อ่านก่อน!

 40 คะแนน • หัวใจของข้อสอบ

🧮 Normalization

1NF–3NF, BCNF, 4NF, 5NF อธิบายทีละขั้นพร้อมภาพ FD, Partial/Transitive/MVD/JD และโจทย์เดินเฉลยเต็มสเต็ป

 Transaction 30 คะแนน

🔄 Recovery Control

Transaction + ACID, Log File, UNDO/REDO, Checkpoint, Deferred vs Immediate Update และโจทย์ recovery จาก log ทีละบรรทัด

 Transaction 30 คะแนน

🔀 Concurrency Control

Lost Update, Dirty Read, Locking (S/X), 2PL, Timestamp, Deadlock และโจทย์ตารางเวลา 2 Transaction ทำงานพร้อมกัน

 15 คะแนน • ไม่ออกออกแบบ

🏢 Data Warehouse

นิยาม 4 ลักษณะของ Bill Inmon, OLTP vs OLAP, ETL, Data Mart, Star vs Snowflake — อ่านเน้นความหมายและตารางเปรียบเทียบ

 15 คะแนน • ทำก่อนในห้องสอบ

💾 SQL

INNER/OUTER JOIN พร้อมแผนภาพเวนน์, Subquery 3 ตำแหน่ง, Correlated Subquery ไล่รันทีละแถว และเทคนิคทำข้อสอบ

 10 คะแนน • หัวข้อใหม่ปีนี้

⚖️ วิพากษ์ Data Model

หลัก No Silver Bullet, เทียบ 3 โมเดล Bill-Centric / Order-Centric / Enterprise Commerce และสูตรตอบข้อสอบ 3 ขั้น
จากรุ่นพี่

🧑‍🎓 รีวิวข้อสอบปีก่อน

ข้อสอบเขียนตอบทั้งหมด, ER บางข้อแบ่ง Req เป็นส่วน ๆ แล้วรวมกัน, SQL เน้น Join + Subquery เหมือนเดิม

📅 แผนอ่านแนะนำ (สำหรับเวลาจำกัด)

เรียงตาม คะแนนต่อเวลาที่ลงทุน — หัวข้อไหนคุ้มที่สุดอ่านก่อน

  1. Normalization (40 คะแนน) — อ่านจนทำโจทย์ 1NF→5NF ได้คล่อง เดินสูตรได้ทุกแบบ
  2. Recovery + Concurrency (30 คะแนน) — ข้อสอบเป็นแบบเดิมซ้ำ ๆ: นิยาม + ตัวอย่าง + เดิน log/schedule
  3. SQL (15 คะแนน) — ฝึกเขียนมือจนคล่อง เพราะในห้องสอบต้อง ทำ SQL เป็นข้อแรก (คำแนะนำรุ่นพี่)
  4. Data Warehouse (15 คะแนน) — ท่องนิยาม 4 ข้อ + ตาราง OLTP vs OLAP ให้ขึ้นใจ (ไม่มีการออกแบบ)
  5. DB Concept (10 คะแนน) — ท่อง 5 คำถามพื้นฐานพร้อมตัวอย่าง
  6. วิพากษ์ Data Model (10 คะแนน) — จำสูตรตอบ 3 ขั้น + โครง 3 โมเดล

✅ เช็คลิสต์เตรียมสอบ (ติ๊กเก็บไว้ได้ — ไม่หายแม้ปิดเบราว์เซอร์)

💡 กลยุทธ์ในห้องสอบ (จากรุ่นพี่ทุกรุ่นย้ำเหมือนกัน)

  • ข้อสอบ เขียนตอบทั้งหมด — ซ้อมเขียนมือ อย่าอ่านผ่านอย่างเดียว
  • ทำ SQL ให้เสร็จก่อน เพราะใช้เวลาเยอะมาก ถ้าไปทำทีหลังอาจไม่ทัน
  • SQL ปีก่อนเน้น Join เยอะ + Subquery เหมือนข้อสอบเก่า — ลองทำข้อสอบเก่าซ้ำ
  • ข้อวิพากษ์/นิยาม ตอบเป็นโครงสร้าง: นิยาม → เหตุผล → ยกตัวอย่าง ได้คะแนนเต็มง่ายกว่าเขียนยาวไปเรื่อย
